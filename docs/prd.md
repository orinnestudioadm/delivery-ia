# 2. Documento de Requisitos do Produto (PRD) - DeliveryIA

## 2.1 Visão Geral do Produto
- Resumo executivo da proposta de valor do DeliveryIA.

## 2.2 Personas e Jornadas do Usuário
- **Persona 1**: Perfil, objetivos, desafios.
- **Jornada principal**: Fluxo ponta a ponta que o usuário realiza.

## 2.3 Requisitos Funcionais (RF)
- [RF01] Descrição da funcionalidade principal.
- [RF02] Autenticação e gestão de perfil via Clerk.
- [RF03] Operações CRUD principais e persistência via Supabase.

## 2.4 Requisitos Não-Funcionais (RNF)
- [RNF01] Performance: tempo de resposta da API < 200ms.
- [RNF02] Segurança: RBAC e proteção de rotas públicas/privadas.
- [RNF03] Acessibilidade: conformidade com WCAG 2.1 AA.

## 2.5 Métricas de Sucesso (KPIs)
- Métricas para avaliar o sucesso do incremento de produto entregue.
