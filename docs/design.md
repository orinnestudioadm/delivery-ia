# 5. Diretrizes de Design e UX (Design System) - DeliveryIA

## 5.1 Identidade Visual e Tipografia
- Fonte primária: Inter / Geist.
- Paleta de cores (Tailwind Tokens: Primary, Secondary, Background, Card, Destructive).
- Modo Claro e Escuro (Dark mode nativo).

## 5.2 Componentes e Padrões de Layout
- Sistema de design baseado em Shadcn UI / Radix Primitives.
- Feedback visual com Toasts e Skeleton loaders.
- Design responsivo (Mobile-first, breakpoints sm, md, lg, xl).

## 5.3 Acessibilidade (A11y)
- Contraste de cores adequado.
- Suporte a navegação por teclado e leitores de tela (aria-*).
